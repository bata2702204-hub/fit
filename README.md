# מעקב אימונים

אפליקציית PWA אישית בעברית (RTL). כל הנתונים נשמרים על המכשיר בלבד.

## העלאה לטלפון (GitHub Pages, חינם)
1. פתח חשבון חינמי ב-github.com.
2. צור repository חדש בשם `fit` (Public).
3. לחץ "uploading an existing file" וגרור פנימה את **כל התוכן** של תיקיית `fit` (כולל התיקיות css, js, icons), ואז Commit.
4. Settings ← Pages ← Source: "Deploy from a branch" ← Branch: `main` / `(root)` ← Save.
5. אחרי כדקה תקבל כתובת: `https://<שם-המשתמש>.github.io/fit/`.
6. בטלפון פתח את הכתובת ב-Chrome (אנדרואיד) או Safari (אייפון) ← תפריט ← "הוסף למסך הבית".

## חשוב
- הנתונים שמורים בדפדפן של אותו טלפון. מחיקת נתוני אתר או הסרת האפליקציה תמחק אותם, לכן **ייצא גיבוי** (הגדרות ← ייצוא נתונים) מדי פעם.
- אחרי עדכון קבצים: העלה שוב והגרסה החדשה נטענת אוטומטית כשיש רשת.

## הרצה מקומית
`python -m http.server 8123` בתיקייה, ואז http://localhost:8123
